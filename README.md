# Houston Skills

[Less but Better](skills/less-but-better/SKILL.md) is a Codex skill for simple, correct code, readable documentation, and relevant replies.

## Install in Codex

```sh
codex plugin marketplace add Djanghao/houston-skills
codex plugin add houston-skills@less-but-better
```

In Codex, use `$houston-skills:less-but-better` or select the skill from `/skills`.
